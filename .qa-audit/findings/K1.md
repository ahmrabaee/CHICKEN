Common fields for all entries: Test executed: no (doc review only). Historical context checked: plan docs listed per item; decision-log.md not consulted at time of writing (K2 parallel). Recommendation: testers verify against code/runtime; do not fix.

### K1-001: Dynamic page access enforced in UI only
- Status: SUSPECTED | Severity: High
- Area: docs/DYNAMIC_PAGE_ACCESS_PLAN.md (~l.197 "backend stays role-based"), docs/ACCOUNTANT_ADMIN_ROLES_PLAN.md §4
- Expected (PRD2 11.9: permissions enforced on API) vs suspected: revoking a page for an accountant hides it but API still serves it; granting e.g. `debts` may be blocked by @Roles.
- Impact: cashier/accountant can reach supplier/cost/financial data via API. Test: per-user page off -> call endpoint directly.

### K1-002: Inventory value tracked by average while lots are FIFO
- Status: SUSPECTED | Severity: High
- Area: FRONT_docs/INVENTORY_COST_ACCOUNTING.md §3, SCENARIO_COST_AND_INVENTORY.md step 6 vs PRD2 6.4 / BP06 §11
- Adjustment decrease reduces `inventory.total_value` proportionally (avg) while lots are consumed FIFO; increase without unitCost adds value at avg cost without a lot. Expected I-14/I-16: Σ lot value = inventory.totalValue = Inventory GL.
- Impact: inventory valuation / COGS misstated.

### K1-003: Stock transfer destination cost user-editable -> value created/destroyed without JE
- Status: SUSPECTED | Severity: High
- Area: docs/STOCK_TRANSFER_FIX_PLAN.md (per-line "cost/kg"), backend_docs/plan_of_wastage.md §4.2 ("manual adjustment"); transfer is "accounting-neutral, no JE"
- Expected I-23: Σ destination lot values = source value consumed. If unit costs are free inputs (or dest grams < source grams with inherited per-unit cost), Σlots ≠ GL inventory.
