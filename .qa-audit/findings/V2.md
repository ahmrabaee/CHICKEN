## Disagreements with original findings
None material. The only deltas are refinements (noted inline above): T5-001's risk is **unconditional** given
DEPLOYMENT.md's actual content (not merely "latent"); T5-003's fallback is **not cwd-dependent** in this build
(absolute path resolution) — it is gated solely by the literal presence/absence of `app/backend/.env`, which is
git-ignored and never fails startup if missing; T4-012/T4-004's "when does the block clear" is answered precisely
(clears only when the highest-numbered row is deleted, not merely when enough rows are deleted); T6-010 is broader
than stated (any `startDate===endDate` sales-list query returns 0, not only the Asia/Jerusalem edge case).
