# 📖 الوحدة 6 — دليل المستخدم في السايدبار (ميزة مقترحة)

> ## ⚠️ هذه **ميزة جديدة** — لم تُنفَّذ، بانتظار موافقتك
> حسب تعليماتك ("ممنوع تضيف أي فيتشر جديدة إلا لو في شيء حيوي ناقص، واسألني قبل") — هذا الملف **خطة فقط**. لن أبدأ التنفيذ قبل موافقتك.

**الهدف المطلوب:** خانة في السايدبار تكون دليل المستخدم لكل قسم، لتقليل اتصالات الدعم.

---

## 💡 التصميم المقترح

### الخيار أ (موصى به) — دليل سياقي لكل صفحة + صفحة دليل شاملة
- عنصر جديد في السايدبار: **"📖 دليل المستخدم"** (`/help`) يفتح صفحة فيها أقسام الدليل (نقطة البيع، المخزون، المحاسبة، ...).
- بالإضافة: زر **"؟"** صغير أعلى كل صفحة يفتح دليل ذلك القسم مباشرةً (سياقي).
- المحتوى عربي، مبسّط، بخطوات مصوّرة/نقاط.

### الخيار ب — صفحة دليل واحدة فقط (أبسط)
- عنصر سايدبار واحد `/help` بصفحة طويلة فيها كل الأقسام بتبويبات.

### الخيار ج — روابط لملفات فيديو/PDF خارجية
- الأبسط، لكن أقل فائدة وغير مدمج.

---

## 🧱 نطاق التنفيذ (للخيار أ)
1. **Route جديد** `/help` في `App.tsx` + صفحة `Help.tsx`.
2. **عنصر سايدبار** في `AppSidebar.tsx` (أيقونة BookOpen/HelpCircle) — متاح لكل الأدوار.
3. **محتوى الدليل:** ملفات Markdown/JSON لكل قسم (نقطة البيع، المخزون، الإتلاف، المشتريات، المدفوعات، الديون، المحاسبة، التقارير، المستخدمون، الإعدادات).
4. (اختياري) زر مساعدة سياقي لكل صفحة.
5. دعم RTL كامل، بحث داخل الدليل.

**التقدير:** متوسط — معظمه محتوى (كتابة الشروحات) وليس كوداً معقداً. الكود ~صفحة + عنصر سايدبار + ملفات محتوى.

---

## ❓ أسئلة لك قبل التنفيذ
1. أي خيار تفضّل (أ / ب / ج)؟
2. المحتوى: أكتبه أنا (مسودة عربية لكل قسم) ثم تراجعه، أم عندك محتوى جاهز؟
3. هل يظهر الدليل لكل الأدوار (مدير + محاسب) أم للمحاسب فقط (هو الأكثر احتياجاً)؟
4. نصوص فقط، أم مع صور/لقطات شاشة؟

---

## قائمة المراجعة (بعد الموافقة والتنفيذ)
- [ ] عنصر "دليل المستخدم" يظهر في السايدبار لكل الأدوار
- [ ] صفحة `/help` تفتح وتعرض الأقسام
- [ ] كل قسم له شرح واضح بالعربية RTL
- [ ] (إن اخترنا السياقي) زر "؟" في كل صفحة يفتح القسم الصحيح
- [ ] البحث داخل الدليل يعمل
- [ ] لا يكسر الصلاحيات (متاح للجميع بأمان — محتوى ثابت فقط)
